# GOEN — 研修医マッチング対策ノート

自分専用のマッチング対策アプリです。

```
大項目：大学・科（例：京大　糖尿病内分泌）
  └ 中項目：病院（例：○○記念病院）
      └ 小項目：直感／忙しさ／定員／倍率／…（すべて自由記述）
```

大項目・中項目・小項目のすべてを、アプリの中から後から追加・編集・並べ替え・削除できます。

## セットアップ（全部で15分くらい）

### STEP 1. Supabase のプロジェクトを作る

1. <https://supabase.com> にアクセスして、GitHub アカウントなどでサインアップ（無料）
2. **New project** をクリック
   - Name：`goen`（何でもOK）
   - Database Password：適当に作って**どこかに控える**
   - Region：`Northeast Asia (Tokyo)`
3. 2分ほど待つとプロジェクトができます

### STEP 2. テーブルを作る

1. 左メニューの **SQL Editor** を開く
2. `supabase-setup.sql` の中身を**全部コピーして貼り付け**
3. 右下の **Run** を押す（"Success" と出れば完了）

これで「自分のデータしか読み書きできない」設定（RLS）まで一気に入ります。

### STEP 3. ログインをパスワード方式にする（クリック3回）

1. 下のリンクを開く
   👉 <https://supabase.com/dashboard/project/jsnnohegdspjmupofdfg/auth/providers>
   （左メニューの **CONFIGURATION → Sign In / Providers** と同じ場所です）
2. リストの中の **Email** の行をクリックして開く
3. **Confirm email** のトグルを **OFF** にする
4. **Save** を押す

これだけです。あとはアプリの最初の画面でメールアドレスと好きなパスワード（6文字以上）を入れて「はじめる」を押せば、その場でアカウントが作られてログインできます。**メールは一通も届きません。**

> ⚠️ 間違えやすい場所
> **Authentication → Emails** の中にある「Confirm sign up」は、**メールの文面テンプレート**なので別物です。
> 探すのは **Sign In / Providers → Email** の中の **Confirm email** トグルです。

<details>

アプリは「メールに届くコードでログインする」方式にも対応していますが、
現在のSupabaseは **カスタムSMTP（Resend など）を設定しないとメール文面を編集できない** 仕様のため、
6桁コードを送るにはSMTPの用意が別途必要です。手間がかかるので、上のパスワード方式を推奨します。

SMTPを設定済みなら、Authentication → Emails → Templates → **Magic link or OTP** を開いて
本文に次の1行を足せば、コード方式が使えるようになります。

```html
<p>ログインコード： <strong>{{ .Token }}</strong></p>
```

### STEP 4. 接続の確認

**URL と anon キーは、いただいた値をすでに `index.html` に書き込んであります。** そのままで動きます。

うまくいっているか確かめたいときは、アプリのログイン画面いちばん下の **「接続テスト」** を押してください。

| 表示 | 意味 |
|---|---|
| ✓ 接続OK。テーブルもできています。 | STEP 1・2 が完了しています |
| テーブルがありません | STEP 2 の SQL をもう一度 Run してください |
| 通信できませんでした | URL / キーを「接続設定」で見直してください |

> anon キーは公開して問題ないキーです（STEP 2 の RLS が守ってくれます）。
> 万一キーを作り直したときは、アプリの「接続設定」から貼り替えられます。

### STEP 5. GitHub に上げる

1. GitHub で **New repository** → 名前を `goen`、**Public** で作成
2. **uploading an existing file** から、このフォルダの中身を**フォルダ構造ごと**ドラッグ&ドロップ
   （`index.html` がリポジトリの一番上に来るように）
3. **Settings** → **Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 1〜2分待つと `https://ユーザー名.github.io/goen/` で開けるようになります

コマンドが使えるなら:

```bash
git init
git add .
git commit -m "GOEN"
git branch -M main
git remote add origin https://github.com/ユーザー名/goen.git
git push -u origin main
```

### STEP 6. スマホのホーム画面に追加する

- **iPhone**：Safari でアプリの URL を開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー → 「アプリをインストール」

これでアイコンから起動でき、アドレスバーのない全画面で使えます。

### STEP 7. 初回ログイン

1. メールアドレスと、自分で決めたパスワード（6文字以上）を入れる
2. 「はじめる」を押す → その場でアカウントが作られてログイン完了

初回に「京大　糖尿病内分泌」「公立大　糖尿病内分泌」と小項目18個が自動で作られます。

## 使い方メモ

- **小項目はすべての病院で共通**です。どこかで1つ追加すると全病院に同じ欄が増えます。
- 記入は**自動保存**（打ち終わって0.5秒で保存）。保存ボタンはありません。
- 病院一覧の **「一覧で比較する」** で、同じ大学・科の病院を横並びの表で見比べられます。
- ホーム画面の検索窓は、**病院名と記入した本文の両方**を横断検索します。
- 圏外・機内モードでも開けて記入できます。オンラインに戻ると自動で送信されます。
- 設定 →「バックアップを書き出す」で全データを JSON で保存できます。

## 困ったとき

**「メールの確認がまだです」と出る**
STEP 3 の **Confirm email** が ON のままです。
**Sign In / Providers → Email → Confirm email** を OFF にして Save したあと、もう一度「はじめる」を押してください。
（Authentication → Emails の「Confirm sign up」はメール文面のテンプレートで、別物です）

**「パスワードが違います」と出る**
一度登録したメールアドレスは、同じパスワードでしか入れません。忘れた場合は
Authentication → **Users** でそのユーザーを削除すれば、また新規登録できます。

**「permission denied」などのエラーが出る**
STEP 2 の SQL が最後まで実行できていない可能性があります。SQL Editor でもう一度全部 Run してください。

**データが同期されない**
病院詳細の「小項目」の横にある「同期」バッジが薄くなっているときは未送信の変更があります。オンラインになると自動で送られます。

**別の端末でも使いたい**
その端末で同じメールアドレスでログインすれば、同じデータが出てきます。

## Supabase を使わずに試す

ログイン画面の「接続設定」→「この端末だけで使う（Supabaseなし）」を選ぶと、
その端末の中だけにデータを保存して使えます（他の端末とは同期されません）。
